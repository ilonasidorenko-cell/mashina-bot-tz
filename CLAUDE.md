# Машина продаж · учебная сборка

## Что это
Telegram-бот с резервной цепочкой LLM-каналов. Стоит на VPS (Hostkey, Нидерланды, Ubuntu 24.04).
Работает под systemd, переживает перезагрузку и падение основного канала.

## Структура
- `bot.py` — Telegram-бот: слушает команды, отвечает через llm.ask.
- `llm.py` — канал к моделям: основной (CLI) + резерв (router, groq, kie).
- `watchdog.py` — сторож: живой вызов модели, алерт владельцу.
- `systemd/` — юниты: mashina-bot.service, mashina-watchdog.timer.
- `failover.log` — лог переключений (не в git).

## Секреты
Ключи лежат в `/etc/solaris/llm.env` (chmod 600), вне репозитория.
В коде ключей быть не должно. В git .env не коммитить.

## Правила
- Язык комментариев — русский.
- Не трогать `/etc/solaris/llm.env` без необходимости.
- Не менять systemd-юниты без перезапуска daemon-reload.

## Как проверять
- `venv/bin/python llm.py` — должен показать «РЕЗЕРВ ОК».
- `systemctl status mashina-bot` — должен быть active (running).
- `claude -p "тест"` — основной канал отвечает.
- Бот в Telegram: `/резерв` — проверка цепочки.

## Грабли
- Cloudflare режет запросы к Groq без User-Agent.
- Имена моделей у провайдеров устаревают — проверять через /v1/models.
- systemd-юнит должен смотреть в актуальную папку проекта.
